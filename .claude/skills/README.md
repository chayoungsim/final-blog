# 프로젝트 스킬 (.claude/skills)

이 프로젝트 전용 Claude Code 스킬을 두는 폴더다. 스킬 하나는 폴더 하나이고, 폴더 안의 `SKILL.md`가 스킬 본문이다.

## 폴더 구조

```
.claude/skills/
├── README.md              # 이 파일 (스킬이 아님)
└── <스킬-이름>/
    ├── SKILL.md           # 필수. 프론트매터 + 지침
    └── (선택) 참고 문서, 스크립트, 템플릿 등 보조 파일
```

- 폴더명은 영문 소문자와 하이픈(kebab-case)으로 짓는다. (예: `add-loader`, `new-component`)
- 보조 파일은 `SKILL.md`에서 상대 경로로 참조한다.

## SKILL.md 형식

```markdown
---
name: 스킬-이름
description: 언제 이 스킬을 써야 하는지 한두 문장. 트리거가 되는 요청 표현을 포함한다.
---

# 스킬 제목

1. 먼저 할 일
2. 이어서 할 일
```

- `name`은 폴더명과 같게 한다.
- `description`이 스킬 선택의 기준이므로, "무엇을 하는지"보다 "어떤 요청에서 쓰는지"를 구체적으로 적는다.
- 본문은 한국어로 작성한다(프로젝트 규칙: 문서화는 한국어).

## 작성 시 참고

- 프로젝트 공통 규칙은 `CLAUDE.md`에 있다. 스킬에 같은 내용을 복사하지 말고 필요하면 `CLAUDE.md`를 참조하게 한다.
- 구조와 흐름은 `docs/architecture/architecture.md`를 참고한다.
- 스킬은 git으로 공유되므로 개인 경로, 토큰, 비밀번호를 넣지 않는다.
